# ForgeFit 1.3.0-beta.1 — cloud-connected Android APK

First downloadable, release-signed ForgeFit Android beta. Download
`ForgeFit-1.3.0-beta.1.apk` below, not the source-code ZIP or an unsigned CI artifact.

## What this APK does

- Installs ForgeFit with its own launcher icon on Android 7.0 or newer.
- Opens the hosted app at https://forgefit-rutvik.netlify.app/ using a Trusted Web Activity.
- Keeps the package small: no embedded web runtime, exercise media, AI model or database.
- Uses the website's passkey sign-in, Neon sync and optional OpenRouter AI configuration.
  Cloud sync and AI need internet; the APK itself does not supply an AI API key.
- Uses the original browser session, rather than moving credentials into an embedded WebView.
- Includes the graphite/orange icon and Apache/AGPL license notices.

Chrome or another Trusted Web Activity-compatible browser is recommended. Open the
downloaded APK on your phone; Android may ask you to allow installations from that
browser/file manager. Install only this repository's signed release asset. Do not
disable Play Protect.

## Beta limitations — please read

- **Actual-device testing is still pending.** Passkey login, cloud sync, an AI request,
  notifications and full-screen behavior have not yet been verified on a phone with
  this APK. This is a beta, not a production-certified or Play Store build.
- **Full-screen verification is pending deployment.** The Netlify site must serve the
  new `/.well-known/assetlinks.json` with this APK's signing certificate. Until then,
  the app falls back to a browser Custom Tab with a visible address bar.
- **It displays the current hosted version.** Premium UI/walkthrough updates on the
  development branch will appear after they are merged and deployed to Netlify. This
  release does not silently merge `main` or change the live deployment.
- This is the cloud-connected package, **not** the separate offline Capacitor flavor.
  Installing it does not migrate data from an older offline openGym installation.
